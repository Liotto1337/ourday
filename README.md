# OurDay — этап 1

Пастельный прототип совместного трекера привычек на Expo/React Native.

## Запуск
1. Установите Node.js LTS.
2. В каталоге проекта выполните `npm install`.
3. Выполните `npx expo start`.
4. Установите Expo Go на телефон и откройте проект по QR-коду (при необходимости используйте `npx expo start --tunnel`).

**Важно:** это только локальный UI-прототип. Данные хранятся в памяти, не сохраняются после перезапуска и не синхронизируются. Кнопка отметки изменяет только отметку текущего пользователя. Для Android/iOS самостоятельных сборок понадобятся дальнейшие этапы.
